# Study deep dives

**One mechanism per page, taken apart until it is yours — with live figures,
runnable code, and every quoted number pinned by a test.**

> An autopsy asks *why did this algorithm get written, and what killed its
> advantage?* A deep dive asks *how does this machinery actually work, and
> where exactly does it stop working?*

The [Predecessors curriculum](../curriculum/00-curriculum.md) studies thirteen
named algorithms as case studies in problem-finding. It moves fast on purpose,
and it leaves collapsed **▸ deeper** boxes behind — places where the real
mathematics was compressed into four paragraphs so the narrative could keep
going. This section is where those boxes get opened.

## The rules of a deep dive

Same house rules as everything else in this repository, plus two of its own:

1. **Build the object, do not cite it.** No result appears here unless the
   code in the same directory computes it. The transform is a character
   table, so a character table gets built; the QFT is a circuit, so the
   circuit is compiled and compared against the matrix it claims to be.
2. **Every number in the prose is pinned by a test.** If a page says the
   leakage mass is $0.787$, a test computes $0.787$ and fails when that stops
   being true. Prose does not get to assert numbers.
3. **The mechanism gets attacked too.** Each deep dive ends with the
   strongest classical case against its own subject — the section that
   explains what the mechanism cannot do, and which classical theorem is
   already standing where you hoped to plant a flag.
4. **Interactive where a picture beats a paragraph.** The widgets are
   built from inline SVG with no dependencies, and they run on the phone in
   your hand.

!!! tip "Never studied Fourier analysis, or studied it long ago?"

    Deep dive 01 assumes you can picture a spectrum. If you cannot — or
    could once and no longer can — read
    [**the optional prerequisite**](00-fourier-primer/notes.md) first. It
    builds the whole thing from "a signal is a list of numbers", needs no
    calculus, and ends by deriving the Hadamard gate as the two-point
    Fourier transform. Everything on it is classical; nothing is quantum.

## How each deep dive is laid out

```
study-deep-dive/NN-topic/
  notes.md            the page: main line, ▸ deeper boxes, widgets, figures
  <topic>_lab.py      from-scratch implementations, importable and documented
  test_<topic>_lab.py one test per claim the prose makes
  fig-*.svg           generated by scripts/make_<topic>_figures.py — light
  fig-*-dark.svg      … and dark; never hand-drawn
```

Interactive widgets live in
[`docs/javascripts/qq-anim.js`](https://github.com/mamuncseru/quantum-advantage-quest/blob/main/docs/javascripts/qq-anim.js)
and are dropped into a page with a one-line `div`. They share the autopsies'
widget vocabulary on purpose: a control that means one thing in autopsy 02
means the same thing here.

```bash
.venv/bin/python -m pytest study-deep-dive/ -q      # every pinned claim
.venv/bin/python scripts/make_fourier_figures.py    # regenerate deep dive 01
```
